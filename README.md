# UART_FPGA_Calculator
Calculator written in VHDL uses uart to transmit and recieve data


Please note that the code for this repository will not be updated in the emulated folder format of xilinx vivado but instead in files detailing the UART transmitter and receiver (will be updated by 12/11/2026 due to accessibility issues), Encoder and Decoder (written with help of a partner), and ALU.
